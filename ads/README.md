# Book trailer files

The pay sheet plays these files, in order, once each:

| File | Title | Link after the trailer |
|---|---|---|
| `ads/dystopia.mp4` | Dystopia: Life After The Machines | https://www.amazon.com/dp/B0H2SGHFNN |
| `ads/borrowed-heartbeat.mp4` | Borrowed Heartbeat | https://www.amazon.com/dp/B0GXP6KYBN |
| `ads/ailt.mp4` | Adaptive Inclusive Leadership Theory (AILT) | https://matthew-culwell-author-page.vercel.app |

These are the book trailers the pay sheet plays. Keep the file names.

If a file is missing, the player shows an error and a retry. Closing that screen does not count a view, and the game keeps running.
