# Steam scaffold

Not a Steam build. steamworks.js is not installed and the app is not
in Steamworks. Episode One is the intended free demo. The premium
price in the plan is $7.99.

`main.js` is an Electron shell that loads `../index.html`. Gamepad
input already lives in the web game. Do not ship this folder as the
Steam app until the depot, the content survey, and the build exist.
